# ⚡ Edwien Janakan — Kinetic Portfolio OS

A high-performance personal portfolio featuring kinetic hardware explosions, interactive physics, custom Web Audio micro-haptics, and developer tools. Built with modern web standards, zero heavy UI frameworks, and hardware-accelerated animations.

---

## ✨ Features & Architecture

* **3D Hardware Disassembly Stage:** Scroll-driven GSAP perspective disassembly of unibody chassis, PCB, silicon die, and thermal cooling layers.
* **Interactive 3D Inspection Mode:** Freeform 360-degree pointer-drag inspection using modern Pointer Capture APIs (cross-browser compatible across Safari, Brave, Chrome, and Firefox).
* **Kinetic Motion Lab:** Continuous SVG vector path animations, spring physics nodes, and orbital mechanics powered by Anime.js.
* **Horizontal Project Glide:** Scrubbed pinned horizontal track for project exploration with 3D mouse parallax cards and dynamic flashlight spotlight overlays.
* **Interactive Developer Shell:** Built-in terminal emulator with functional commands, live easter eggs (`matrix` digital rain, `tictactoe` AI mini-game, `sound` frequency generator, and theme switcher).
* **Synthesized Web Audio Haptics:** Custom oscillator-based UI sound effects synthesized in real time via the Web Audio API with an active mute toggle.
* **Custom Magnetic Fluid Cursor:** Lerp-interpolated dual-layer custom cursor with hover expansion and automated window leave/enter detection.
* **Anti-Scraper Bot Shield:** Runtime JavaScript contact obfuscation and honeypot traps to prevent automated scrapers from harvesting communication endpoints.
* **Dynamic Theme Switcher:** Real-time CSS variable engine supporting Azure Blue, Cyber Neon, and Minimal Monochrome themes.

---

## 🛠️ Tech Stack

* **Core:** Semantic HTML5, CSS3, Modern ES6+ JavaScript
* **Styling:** Tailwind CSS (CDN), Custom CSS Variables & Glassmorphism
* **Animation Engines:** GSAP (ScrollTrigger), Anime.js, Lenis Smooth Scroll
* **Audio Engine:** Web Audio API (native browser synthesis)
* **Icons:** Feather Icons
